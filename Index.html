How the Special ID Works

The number of letters represents the number of digits the user can customize in their Special ID.

Example

  • ABCDEF × 7 Days → User can select 6 digits
  • ABCDE × 7 Days → User can select 5 digits
  • ABCD × 7 Days → User can select 4 digits

Activity Rules

Important

Recharge amount is calculated on a weekly basis, from Monday through Sunday. The following Monday, the previous week’s qualifying recharge will be reviewed and the applicable Noble Status will be issued.
